Политика конфиденциальности Sidorovich Bot

Дата последнего обновления: 28 октября 2026 года

1. Общие положения

Настоящая Политика конфиденциальности описывает порядок обработки данных при использовании Sidorovich Bot (далее — «Бот»), работающего на платформе Discord.

Бот предоставляет функции общения с искусственным интеллектом, голосового взаимодействия, воспроизведения музыки, модерации и другие доступные возможности.

Используя Бота, пользователь подтверждает, что ознакомился с настоящей Политикой.

2. Какие данные могут обрабатываться

В зависимости от используемых функций Бот может обрабатывать следующие категории данных:

- Идентификаторы Discord: идентификаторы пользователей, серверов и каналов, необходимые для выполнения команд.
- Сообщения и команды: текст запросов, сообщения, переданные Боту, и данные, необходимые для формирования ответов.
- Данные взаимодействия с ИИ: содержание запросов и контекст, необходимый для генерации ответов.
- Голосовые данные: аудиоданные, переданные для распознавания речи, и полученные текстовые транскрипции, если голосовые функции используются.
- Технические данные: сведения об ошибках, событиях работы Бота и состоянии выполнения команд, если они регистрируются системой.
- Данные для работы функций: информация, необходимая для хранения настроек, истории взаимодействия или выполнения других команд, если соответствующие функции реализованы.

Фактический состав данных зависит от версии Бота и настроек его работы.

3. Для чего используются данные

Данные могут обрабатываться для следующих целей:

- выполнение команд Discord;
- предоставление ответов искусственного интеллекта;
- распознавание речи и создание голосовых ответов;
- обеспечение работы музыкальных и модерационных функций;
- сохранение необходимых настроек и состояния системы;
- диагностика ошибок, обеспечение безопасности и предотвращение злоупотреблений;
- обработка обращений пользователей.

4. Голосовые функции

При использовании голосовых команд Бот может получать аудиоданные из голосового канала Discord, преобразовывать речь в текст и передавать запрос для обработки искусственному интеллекту.

Для распознавания речи, обработки текста и синтеза голоса могут использоваться внешние сервисы.

В зависимости от реализации отдельные данные могут передаваться таким сервисам для выполнения соответствующих функций. Обработка данных этими сервисами также может регулироваться их собственными политиками конфиденциальности.

Пользователям следует учитывать особенности голосового взаимодействия и правила Discord при использовании Бота в общих голосовых каналах.

Не следует отправлять через Бота пароли, платёжные данные, документы и другую конфиденциальную информацию, если это не требуется для конкретной функции.

5. Хранение данных

Для работы Бот может использовать базу данных PostgreSQL и технические журналы.

Срок хранения зависит от типа данных, назначения функции и настроек системы. Данные должны храниться только в течение периода, необходимого для заявленных целей, если более длительный срок не требуется законом.

Точный срок хранения каждой категории данных определяется фактической конфигурацией Бота.

6. Передача данных третьим лицам

Данные могут передаваться внешним поставщикам услуг, если это необходимо для работы Бота, в частности:

- Discord — для взаимодействия с платформой;
- поставщикам моделей искусственного интеллекта — для обработки запросов;
- поставщикам распознавания речи и синтеза голоса — для голосовых функций;
- поставщикам хостинга и инфраструктуры — для обеспечения работы системы.

Передача осуществляется в объёме, необходимом для соответствующей функции, с учётом применимых требований законодательства и условий используемых сервисов.

Бот не должен продавать персональные данные пользователей.

При этом ни одна система хранения и передачи данных не может гарантировать абсолютную безопасность.

Пользователи также должны соблюдать меры предосторожности и не передавать Боту секретную информацию.
